# Madhav Computers

Simple responsive public website for Madhav Computers in Jodhpur, Rajasthan.

## Run locally

```text
npm start
```

Then open `http://localhost:3000`.

## Hostinger

Import the repository and use `npm start` as the start command. Hostinger supplies the `PORT` environment variable automatically.

The website intentionally excludes Udyam registration and other private certificate identifiers.
